# 1. 概念
表中一定要有各种约束，通过约束让我们未来插入数据库表中的数据是符合预期的。约束本质是通过技术手段，倒逼程序员插入正确的数据。反过来，站在mysql的视角，站在mysql的视角，凡是插入进来的数据，都是符合数据约束的。
约束的最终目标：保证数据的完整性和可预期性
为了更好的进行表的约束，就需要更多的表的约束

# 3. 列描述
相当于对某一列进行描述
用法示例：
```SQL
create table if not exists t14( 
	name varchar(20) not null comment '这个是用户名', 
	age tinyint unsigned default 18 comment '这个是用户的年龄', 
	gender char(1) default '男' comment '这个是用户的性别' 
);
```

>注意：not null和default一般不需要同时出现，因为default本身有默认值不会为空

# 1.5 主键约束
主键：primary key用来唯一的约束该字段里面的数据，不能重复，不能为空，一张表中最多只能有一个主键，主键所在的列通常是整数类型。（学号，身份证等可以唯一标识某个人的）
使用：
![[主键的设置.png]]
会自动加上非空约束！
![[MySQL对主键的描述.png]]
主键一定是不冲突的，根据主键绝对能拿出唯一的一条数据，意义在于可以针对性的唯一的查找某一个数据。
主键可以去掉，实际上也就是对主键的删除：
```SQL
alter table test_key drop primary key;
```
同样的添加主键：
```SQL
alter table test_key add primary key(id);
```
>不要等表使用了一段时间后才加主键，不然有重复数据的话就可能需要删除一些数据就很坑

一张表中只有一个主键，并不意味着一个表中的主键只能添加给一列，一个主键可以被添加到一列，或者多列上--复合主键
```SQL
create table pick_course( 
	id int unsigned, 
	course_id int unsigned comment '课程编号', 
	score tinyint unsigned comment '这个学生课程考的分数', 
	primary key (id,course_id) 
);
```
![[主键不在一列上.png]]
证明这是一个主键，他们两个数据合起来才是一个主键。
这个的主键约束是不让一个学生重复选一个课程！换而言之，两个合起来才称为一个主键，单独拿出来是可以重复的！
