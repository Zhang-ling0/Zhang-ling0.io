# MySQL 内置函数

> [!summary] 学习目标
> 掌握 MySQL 中常用的日期、字符串、数学和其他函数，能够把函数用于查询条件、字段展示、表结构设计与实际题目中。

本文整理自 [[Codex Attachments/07-MySQL内置函数.pdf]]，内容覆盖原文档第 7.1-7.5 节。

## 1. 日期函数

### 1.1 常用日期函数

| 函数 | 描述 |
| --- | --- |
| `current_date()` | 当前日期 |
| `current_time()` | 当前时间 |
| `current_timestamp()` | 当前日期时间 |
| `date(datetime)` | 返回 `datetime` 参数的日期部分 |
| `date_add(date, interval d_value_type)` | 在 `date` 中添加日期或时间；`interval` 后的数值单位可以是 `year`、`minute`、`second`、`day` |
| `date_sub(date, interval d_value_type)` | 在 `date` 中减去日期或时间；`interval` 后的数值单位可以是 `year`、`minute`、`second`、`day` |
| `datediff(date1, date2)` | 计算两个日期的差，单位为天 |
| `now()` | 当前日期时间 |

### 1.2 获得日期、时间与日期时间

获得年月日：

```sql
select current_date();
```

```text
+----------------+
| current_date() |
+----------------+
| 2017-11-19     |
+----------------+
```

获得时分秒：

```sql
select current_time();
```

```text
+----------------+
| current_time() |
+----------------+
| 13:51:21       |
+----------------+
```

获得当前日期时间：

```sql
select current_timestamp();
```

```text
+---------------------+
| current_timestamp() |
+---------------------+
| 2017-11-19 13:51:48 |
+---------------------+
```

> [!note] “时间戳”的含义
> 原文档将 `current_timestamp()` 称为“当前时间戳”，但它返回的是 `DATETIME`/`TIMESTAMP` 类型的日期时间，不是 Unix 纪元秒数。若需要 Unix 时间戳，可使用 `unix_timestamp()`。

只保留日期部分：

```sql
select date(now());
```

### 1.3 日期加减

在日期基础上增加日期或时间：

```sql
select date_add('2017-10-28', interval 10 day);
```

```text
+-----------------------------------------+
| date_add('2017-10-28', interval 10 day) |
+-----------------------------------------+
| 2017-11-07                              |
+-----------------------------------------+
```

增加其他单位：

```sql
select date_add(now(), interval 10 second);
select date_add(now(), interval 10 minute);
```

在日期基础上减去时间：

```sql
select date_sub('2017-10-1', interval 2 day);
```

```text
+---------------------------------------+
| date_sub('2017-10-1', interval 2 day) |
+---------------------------------------+
| 2017-09-29                            |
+---------------------------------------+
```

### 1.4 计算两个日期的差值

```sql
select datediff('2017-10-10', '2016-9-1');
```

```text
+------------------------------------+
| datediff('2017-10-10', '2016-9-1') |
+------------------------------------+
| 404                                |
+------------------------------------+
```

`datediff(date1, date2)` 按“前一个日期减后一个日期”计算，结果单位为天。

### 1.5 案例 1：记录生日

创建一张记录生日的表：

```sql
create table tmp(
    id int primary key auto_increment,
    birthday date
);
```

添加当前日期：

```sql
insert into tmp(birthday) values(current_date());
```

查询结果：

```sql
select * from tmp;
```

```text
+----+------------+
| id | birthday   |
+----+------------+
|  1 | 2017-11-19 |
+----+------------+
```

### 1.6 案例 2：留言表

创建留言表：

```sql
create table msg (
    id int primary key auto_increment,
    content varchar(30) not null,
    sendtime datetime
);
```

插入数据：

```sql
insert into msg(content, sendtime) values('hello1', now());
insert into msg(content, sendtime) values('hello2', now());
```

查看全部留言：

```sql
select * from msg;
```

```text
+----+---------+---------------------+
| id | content | sendtime            |
+----+---------+---------------------+
|  1 | hello1  | 2017-11-19 14:12:20 |
|  2 | hello2  | 2017-11-19 14:13:21 |
+----+---------+---------------------+
```

只显示发布日期，不显示时间：

```sql
select content, date(sendtime) from msg;
```

查询 2 分钟内发布的帖子：

```sql
select *
from msg
where date_add(sendtime, interval 2 minute) > now();
```

等价写法更容易理解：

```sql
select *
from msg
where sendtime > date_sub(now(), interval 2 minute);
```

时间关系如下：

```text
发送时间                              当前时间 now()
   |                                       |
   |------- 2 分钟有效区间 ----------------|
   |                                       |
发送时间 + 2 分钟 > 当前时间时，帖子仍处于 2 分钟窗口内
```

## 2. 字符串函数

### 2.1 常用字符串函数

| 函数 | 描述 |
| --- | --- |
| `charset(str)` | 返回字符串的字符集 |
| `concat(string2 [, ...])` | 连接字符串 |
| `instr(string, substring)` | 返回 `substring` 在 `string` 中出现的位置；没有出现则返回 `0` |
| `ucase(string2)` | 转换成大写 |
| `lcase(string2)` | 转换成小写 |
| `left(string2, length)` | 从 `string2` 的左边起取 `length` 个字符 |
| `length(string)` | 返回字符串长度，单位为字节 |
| `replace(str, search_str, replace_str)` | 在 `str` 中用 `replace_str` 替换 `search_str` |
| `strcmp(string1, string2)` | 逐字符比较两个字符串的大小 |
| `substring(str, position [, length])` | 从 `str` 的 `position` 位置开始，取 `length` 个字符；省略 `length` 时取到末尾 |
| `ltrim(string)`、`rtrim(string)`、`trim(string)` | 去掉前空格、后空格或前后空格 |

### 2.2 查看字符集

获取 `emp` 表 `ename` 列的字符集：

```sql
select charset(ename) from EMP;
```

### 2.3 拼接字符串

要求显示学生信息，格式为：

> `XXX 的语文是 XXX 分，数学 XXX 分，英语 XXX 分`

原文档示例：

```sql
select concat(name, ' 的语文是 ', chinese, ' 分，数学是 ', math, ' 分 ')
as ' 分数 '
from student;
```

> [!note] 表名与字段说明
> 原文档文字写的是 `exam_result` 表，但示例 SQL 使用了 `student` 表，且示例只拼接了语文和数学。表中存在英语成绩时，可按同样方式补上 `english` 字段。

### 2.4 求字符串占用的字节数

```sql
select length(name), name from student;
```

> [!important] `length()` 计算的是字节数
> `length()` 返回字符串长度时以字节为单位。多字节字符会计算多个字节，单字节字符计算一个字节。例如，字母和数字通常各占一个字节，一个中文字符占用的字节数取决于字符集编码。

### 2.5 替换、截取与大小写转换

将 `EMP` 表中所有名字里的 `S` 替换成“上海”：

```sql
select replace(ename, 'S', '上海'), ename from EMP;
```

截取 `EMP` 表中 `ename` 字段的第二个到第三个字符：

```sql
select substring(ename, 2, 2), ename from EMP;
```

以首字母小写的方式显示所有员工的姓名：

```sql
select concat(lcase(substring(ename, 1, 1)), substring(ename, 2))
from EMP;
```

去掉字符串前后的空格：

```sql
select trim('  hello  ') as result;
select ltrim('  hello  ') as result;
select rtrim('  hello  ') as result;
```

## 3. 数学函数

### 3.1 常用数学函数

| 函数 | 描述 |
| --- | --- |
| `abs(number)` | 绝对值函数 |
| `bin(decimal_number)` | 十进制转换成二进制 |
| `hex(decimalNumber)` | 转换成十六进制 |
| `conv(number, from_base, to_base)` | 进制转换 |
| `ceiling(number)` | 向上取整 |
| `floor(number)` | 向下取整 |
| `format(number, decimal_places)` | 格式化数字，保留指定小数位数 |
| `rand()` | 返回随机浮点数，范围为 `[0.0, 1.0)` |
| `mod(number, denominator)` | 取模、求余 |

> [!note] 原文表格重复项
> 原文档的数学函数表重复列出了 `hex(decimalNumber)`，两次描述均为“转换成十六进制”，这里合并为一项，未丢失函数信息。

### 3.2 数学函数示例

绝对值：

```sql
select abs(-100.2);
```

向上取整：

```sql
select ceiling(23.04);
```

向下取整：

```sql
select floor(23.7);
```

保留 2 位小数，小数部分四舍五入：

```sql
select format(12.3456, 2);
```

产生随机数：

```sql
select rand();
```

## 4. 其他函数

### 4.1 常用其他函数

| 函数 | 描述 |
| --- | --- |
| `user()` | 查询当前用户 |
| `md5(str)` | 对字符串进行 MD5 摘要，得到一个 32 位字符串 |
| `database()` | 显示当前正在使用的数据库 |
| `password()` | MySQL 数据库使用该函数对用户加密 |
| `ifnull(val1, val2)` | 如果 `val1` 为 `null`，返回 `val2`；否则返回 `val1` 的值 |

### 4.2 查询当前用户

```sql
select user();
```

### 4.3 MD5 摘要

```sql
select md5('admin');
```

```text
+----------------------------------+
| md5('admin')                     |
+----------------------------------+
| 21232f297a57a5a743894a0e4a801fc3 |
+----------------------------------+
```

相同的输入会得到相同的 32 位十六进制摘要。原文档用 MD5 说明密码不应以明文形式直接保存。

> [!warning] MD5 不适合现代密码存储
> MD5 是快速、可碰撞的摘要算法，不应再用于新系统中的密码保护。学习环境中出现 MD5 时，重点应放在“摘要结果是等长字符串”这一概念上。

### 4.4 查询当前数据库

```sql
select database();
```

### 4.5 `password()` 函数

```sql
select password('root');
```

```text
+-------------------------------------------+
| password('root')                          |
+-------------------------------------------+
| *81F5E21E35407D884A6CD4A731AEBFB6AF209E1B |
+-------------------------------------------+
```

> [!warning] 版本限制
> `password()` 是旧版 MySQL 教材中的函数，已被弃用，并在 MySQL 8.0 中移除。现代 MySQL 使用认证插件和专用密码哈希流程，不能把该示例直接迁移到新版本。

### 4.6 `ifnull()` 函数

`val1` 不为 `null` 时，返回 `val1`：

```sql
select ifnull('abc', '123');
```

```text
+----------------------+
| ifnull('abc', '123') |
+----------------------+
| abc                  |
+----------------------+
```

`val1` 为 `null` 时，返回 `val2`：

```sql
select ifnull(null, '123');
```

```text
+---------------------+
| ifnull(null, '123') |
+---------------------+
| 123                 |
+---------------------+
```

可把 `ifnull(val1, val2)` 理解为二选一表达式：

```text
val1 不是 null  -> 返回 val1
val1 是 null    -> 返回 val2
```

## 5. 实战 OJ

### 题目：查找字符串 `'10,A,B'` 中逗号 `','` 出现的次数 `cnt`

题目链接：[牛客网 - 查找字符串中逗号出现的次数](https://www.nowcoder.com/practice/e3870bd5d6744109a902db43c105bd50)

参考题解：

```sql
select length('10,A,B') - length(replace('10,A,B', ',', '')) as cnt;
```

解题思路：

1. `length('10,A,B')` 得到原字符串的字节数。
2. `replace('10,A,B', ',', '')` 删除所有逗号。
3. 再对替换后的字符串求 `length()`。
4. 两个长度相减，差值就是逗号占用的总字节数，也就是逗号出现的次数。

由于逗号是单字节字符，本题可以直接使用 `length()`。如果统计的是可能多字节的字符，可考虑改用 `char_length()`。

## 6. 复习速查

| 场景 | 常用函数 |
| --- | --- |
| 当前日期、时间 | `current_date()`、`current_time()`、`now()`、`current_timestamp()` |
| 日期加减 | `date_add()`、`date_sub()` |
| 日期差 | `datediff()` |
| 日期截取 | `date()` |
| 字符串拼接 | `concat()` |
| 字符串查找与替换 | `instr()`、`replace()` |
| 字符串截取 | `left()`、`substring()` |
| 字符串长度 | `length()`、`char_length()` |
| 大小写转换 | `ucase()`、`lcase()` |
| 数值处理 | `abs()`、`ceiling()`、`floor()`、`format()`、`mod()` |
| 随机数 | `rand()` |
| 当前用户与数据库 | `user()`、`database()` |
| 空值处理 | `ifnull()` |

> [!tip] 学习重点
> 内置函数既可以作为 `select` 的返回列，也可以出现在 `where` 等查询条件中。应用时先判断函数的输入和返回值类型，再把函数结果与目标条件进行比较。
